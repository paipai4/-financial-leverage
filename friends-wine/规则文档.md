# 朋友的酒 — 流程化规则规格（编程核查版）

> 本文把《朋友的酒规则书.txt》（原版条文）编译为**可逐条校验的流程规格**：每一条都有
> 编号、触发时机、前置条件、动作、数值公式与失败分支，可直接对照 `rules.js` 与测试用例。
> 标注 **[实现口径]** 的条目是原书有歧义处本模块的既定处理，编程对照以本文为准。

符号约定：玩家人数 **P**（2~6）；城市数 **C = P + 1**；现金单位 **万元**；
房价倍数 **H[c]**（每城独立，初始 1）；政府关系 **G[c][p]**、银行关系 **B[c][p]**（初始 0）；
全局阶段计数 **t**（自 1 起跨回合累加，每阶段 +1）；当前回合 **R**（1~4）、阶段 **p**（1~6 封顶）。

---

## 1. 初设（setup）

| 编号 | 流程 |
|---|---|
| S-1 | 人数解析：`options.players` 优先 → 旧剧本名 `双人局/三人局/四人局` 兼容 → 默认 2；<2 抬到 2，>6 裁到 6。城市数 C = P+1，城市按序命名。 |
| S-2 | 每玩家现金 = 1000，全部存活。 |
| S-3 | 第 1 回合牌堆洗匀后**从左到右轮流发入**各城：银行为 `[贷款构成表 §10-1]`，政府池为 `[土地构成表 §10-2]`（叠底到顶顺序即翻出顺序）。 |
| S-4 | 按座次（Wang→Li→Zhao→Sun→Qian→Zhou）每人一次：选一城 → 从该城政府池**顶部**取 1 张土地入手（绑定该城）→ 下一位。全部选完后进入第 1 回合。**[实现口径]** 原文“可选择 1 个城市免费抽取一张土地”，抽取顺序即座次序。 |

## 2. 回合循环（R = 1..4）

| 编号 | 流程 |
|---|---|
| R-1 | 回合开始：剩余在袋（流拍/被收回）的牌 + 本回合新牌**洗匀后从左到右轮流**发入各城银行池/政府池（各城数量尽量均匀，R1 因构成表有 +1 张会出现 5/4 分布）。 |
| R-2 | 发给每位存活玩家本回合手牌（数量见 `[手牌构成表 §10-3]`，**回合间累积不清零**）。 |
| R-3 | **阶段循环**（p 自 1 起）：
  1. 阶段内固定顺序：**还款 → 出牌窗口 → 拍卖 → 卖房**；
  2. p 到 4 结束时若仍有任何城银行/政府池非空 → p=5（追加拍卖阶段）；p=5 结束仍非空 → p=6；**p=6 结束必进回合收尾**；
  3. 每阶段 t 先 +1。 |
| R-4 | **回合结束（收尾）**：交付房产与维权结算（§7）→ 逮捕检查（§7-3）→ 存活人数判定 → R<4 进下一回合，R=4 进终局（§8）。 |

## 3. 还款（每阶段第一步）

| 编号 | 流程 |
|---|---|
| D-1 | 触发：所有满足 `due ≤ t` 且持有人存活的贷款，按 `due` 升序、uid 字典序逐个处理。 |
| D-2 | **偿付**：现金 ≥ `本金 × 倍数` → 扣现金、贷款移除、记日志；可用本阶段新拍贷款所得现金（先还后拍，天然满足）。 |
| D-3 | **展期（现金不足时）**：该城银行关系 B>6 → 免费展期 2 阶段（`due += 2`）；B>3 → 展期 1 阶段。**同阶段同笔贷款只展期一次**（`last_defer = t` 防死循环）。 |
| D-4 | **破产**：现金不足且无法展期 → 该玩家出局：清除其手牌、其名下贷款、其他城消费者池中其地块（各地原书：[实现口径] 直接移除，不入回炉袋）。 |

## 4. 出牌窗口（每阶段第二步）

| 编号 | 流程 |
|---|---|
| W-1 | 轮转顺序：存活玩家从 `(7t + R) mod P` 席位起循环；**无牌可打或该卡无合法目标自动跳过**。 |
| W-2 | 每人每阶段**限打 1 张**；打出手牌立即从手牌移除；需要目标时进入目标选择状态（选城/选人/选自己地块/选自己贷款/旋转门方向）。**[实现口径]** 所有卡统一在窗口打出（原书“拍卖前”标注的卡在此窗口，其余卡按同一时机简化处理）。 |
| W-3 | 窗口结束 → 构建拍卖队列（§5-1）。 |

## 5. 拍卖（每阶段第三步）

### 5-1 队列构建

| 编号 | 流程 |
|---|---|
| A-0 | 优先拍品（本阶段打出的【定向招拍】【额外贷款】抽出的牌）排最前；随后按城市**自左到右**、每城**先贷款后土地**各翻 1 张（银行池/政府池非空才翻，翻出即从池顶移除）。 |

### 5-2 贷款拍卖

| 编号 | 流程 |
|---|---|
| A-1 | 起拍 **1.5×**，步进 **0.5×**，封顶 **5×**（报价集合 {15..50, step 5}（×10 表示））。 |
| A-2 | 轮流叫价/弃拍：**报价必须严格高于当前最高**；弃拍即本轮永久退出该拍品。 |
| A-3 | **成交判定**：最后一位未弃拍者即中标者（存在最高价时）；无人出价（全员弃拍）→ **流拍**：牌回炉 `leftover`，下回合重洗入场。 |
| A-4 | **[实现口径·顶价抢标]** 因严格加价不存在同价；原书“银行关系更高者可抢标”只在**封顶 5× 成交时**生效：若有其他存活玩家在该城银行关系严格高于中标者 → 该玩家以 5× 顶价抢得。 |
| A-5 | 中标效果：现金 += 本金；生成贷款记录 `{本金, 倍数, 到期 = t + (6 - R)}`（R 为当前回合数）；该城银行关系 +1。 |
| A-6 | **转贷（中标后立刻选择，仅中标者）**：扣押金一半 → 该城政府关系 +1；扣押金全额 → +2（现金不足的选项不提供）；贷款仍归中标者偿还。 |

### 5-3 土地拍卖

| 编号 | 流程 |
|---|---|
| A-7 | **压场直购**：若存在玩家满足 `G[c][p] ≥ 其他所有存活玩家 G 值 + 2` 且现金 ≥ 底价 → 跳过竞拍，该玩家**以底价购得**，房价 H[c] +1。**[实现口径]** 自动结算，不询问。 |
| A-8 | 否则进入竞拍：起拍 **2×**，步进 **1×**，封顶 **10×**；**出价须现金充足**（`底价 × 倍数 ≤ 现金`，不足的倍数不出现在选项中）。 |
| A-9 | 成交：现金 -= `底价 × 倍数`；土地入手（绑定城市）；房价更新：**H[c] += 1**，且成交倍数 ≥4 时**额外 +1**，≥8 时**再额外 +1**（即 +1/+2/+3）。 |
| A-10 | 流拍规则同 A-3（回炉）。 |

## 6. 卖房（每阶段第四步）

| 编号 | 流程 |
|---|---|
| SE-1 | 存活玩家轮转，每人自动进入，可反复执行下述操作，最后点“结束卖房”移交下家： |
| SE-2 | **卖**：任一手牌地块（绑定城 c）→ 放入消费者池，现金 += `底价 × H[c]`（价格随当前房价倍数即时结算）；生成池中地块 `{所属者, 底价, 城市, 交付状态=否}`。 |
| SE-3 | **建**：消费者池中自己名下的未交付地块 → 支付 `底价` 现金 → 状态置为已交付（回合结束时移除出游戏）。现金不足不可选。 |
| SE-4 | 上限约束：不卖房时全城合计最多持有 2 块未售土地。**[实现口径]** 仅提示不强制（可清仓度）。 |

## 7. 回合结束（收尾）

| 编号 | 流程 |
|---|---|
| E-1 | **交付**：消费者池已交付地块 → 移除出游戏。 |
| E-2 | **维权标记**：每块未交付地块 → 其所属者在本城维权标记 +1（所属者已出局则不计）。 |
| E-3 | **维权结算**：每城每玩家当标记 ≥3 时循环：标记 -3；该城政府关系 -1；**收回一块地**：取该玩家在该城“手上未售 + 池中未交付”里**底价最高**者（同价优先收手上未售，[实现口径] 原文“如价格相同优先收回未卖房”），移除并回炉 `leftover`（下回合重洗再入场）。 |
| E-4 | **逮捕**：任一城 `G[c][p] ≤ -2` → 该玩家出局（资产清理同 D-4）。 |
| E-5 | 存活 1 人 → 立即终局胜；存活 0 人 → 按现金排名取最高者终局；否则 R<4 → 下一回合；R=4 → 终局结算（§8）。 |

## 8. 终局（第 4 回合最后阶段收尾后）

| 编号 | 流程 |
|---|---|
| F-1 | 存活玩家中现金最高者获胜；并列则并列胜利；日志输出全部玩家按现金降序的最终排名（存活者优先）。 |

## 11. 数值边界与实现口径清单（对照代码）

| 编号 | 项 | 值/口径 |
|---|---|---|
| V-1 | 人数 | 2~6；人数/腰围越界裁剪；城市数始终 P+1 |
| V-2 | 初始现金 | 1000 |
| V-3 | 到期公式 | `due = 拍得时 t + (6 - R)`；偿付判据 `due ≤ 当前 t` |
| V-4 | 利率 | 贷款还款额 = 本金 × 倍数（倍数即竞拍结果，含 0.5 步进的半倍数） |
| V-5 | 展期 | B>6 展 2；B>3 展 1；同阶段同笔仅一次 |
| V-6 | 房价 | 成交 +1 / ≥4× 再 +1 / ≥8× 再 +1；直购按 +1；卡牌 ± 按各自公式 |
| V-7 | 顶价抢标 | 仅贷款 5× 成交且存在更高银行关系者 |
| V-8 | 优先级 | 定向招拍/额外贷款拍品在队列最前（展示标记） |
| V-9 | 流拍 | 原地回炉 leftover，下回合重洗 |
| V-10 | 收回地块 | 取最高底价，同价先手牌；回炉 leftover |
| V-11 | 逮捕 | 回合收尾检查 `G ≤ -2`，任一城触发即出局 |
| V-12 | 破产清理 | 手牌、名下贷款、他城池中该玩家地块、全部清除 |
| V-13 | 手牌跨回合 | 累积保留 |
| V-14 | DLC | 信用评级 / 融资平台：**不实现** |
| V-15 | 随机数 | 计数式 PRNG 存于 `game.rng`，JSON 往返后结果一致（测试依赖） |
