# 朋友的酒（Friends Wine）

原创 N 人房地产博弈桌面游戏的规则引擎与网页对局界面，作为 **RallyTheTroops（RTT）** 联机对战平台的规则模块实现。

> 你拍地、放贷、转贷、造房、维权——价格是别人的倍数，债是自己的倍数。

## 游戏简介

- **人数**：2 ~ 6 位玩家（「玩家人数 + 1」座城市，每人初始 1000 万现金）
- **结构**：4 个回合（创立 / 发展 / 兴盛 / 离场），每回合 4~6 个阶段，阶段流程为
  **还款 → 拍卖 → 卖房**；第 4 回合结束时现金最多者获胜
- **三池机制**：银行池竞拍「偿还倍数」放贷；政府池竞拍「底价倍数」购地；
  消费者池回收土地换取现金、也可支付造房费交付房产
- **关系与风险**：政府关系（≤ -2 会被逮捕）、银行关系（>3 / >6 免费债务展期）、
  维权标记（每 3 个收回一块地）；资不抵债直接破产离场
- **花式手牌**：围猎、回扣、炒房团、楼市大热、双规、境外融资、定向招拍、
  房闹、金融监管、塌方型腐败、展期谈判、房住不炒、保交楼、金融反腐……

完整规则书见 [friends-wine/朋友的酒规则书.txt](friends-wine/朋友的酒规则书.txt)（由官方 PDF 提取整理，
原文在“回合的最后阶段”一节截断处已注明）。

## 仓库结构

```
friends-wine/
├── rules.js             RTT 规则引擎（状态机 + 拍卖 + 卡牌效果，可 JSON 序列化）
├── play.html/play.js/play.css/data.js   对局界面（地图点击高亮 + 竞拍弹窗）
├── 朋友的酒规则书.txt    规则书文本
├── test_friends_wine.js  无头测试：基本断言 + 多种子随机压测 + JSON 往返
├── about.html / create.html / title.sql / thumbnail.jpg / cover.1x/2x.jpg
└── README.md             实现细节与规则歧义处理说明
register-friends-wine.js  向 RTT 服务器注册本模块的脚本
```

## 在 RTT 服务器上安装

1. 将 `friends-wine` 目录放入服务器 `public/` 下
2. 执行 `node register-friends-wine.js`（向 `titles` 表注册；等同
   `sqlite3 db < public/friends-wine/title.sql`）
3. 重启服务器后在首页即可看到「朋友的酒」

## 本地测试

```bash
cd friends-wine
node test_friends_wine.js          # 全部（6 种子 × 座位配置）
node test_friends_wine.js quick    # 快速冒烟
```

## 界面交互

- 可操作目标统一橙色高亮，直接点击地图：城市列（选城）、手牌（打牌/卖地）、
  侧栏座位卡（选目标玩家）、消费者池地块（支付造房费）
- 每一次竞拍弹出竞拍窗口：拍品金额、当前最高价、叫价倍数按钮、弃拍
- 顶部按钮栏只保留确认/跳过类动作；日志采用 POG 风格色带

## 引擎实现说明

- `game` 完全 JSON 可序列化，随机数为计数式（`game.rng`），数据库往返后仍确定性一致
- 全局阶段计数器驱动还款到期（第 r 回合拍得的贷款在 `6-r` 个阶段后到期）
- 规则歧义处理与取舍（土地归属城市、出牌时机、顶价抢标等 7 条）见
  [friends-wine/README.md](friends-wine/README.md)
